# Unreal Engine 5.8 fixtures

These fixtures were generated by the local `CUE4ParseFixtures` Unreal Engine
5.8 Shipping project. They are deterministic inputs for CUE4Parse integration
tests, not samples from a shipped game.

`manifest.json` records the exact Engine revision, file sizes, and SHA-256
hashes of every persistent binary fixture for provenance. Tests validate that
the manifest covers the fixture set, but deliberately avoid asserting exact
binary sizes, hashes, or byte-for-byte equality.

`SourceTextures` contains the complete deterministic ImageMagick outputs used
to generate the cooked textures. Decoder tests compare every pixel of their
Skia bitmaps against these references with format-specific lossy tolerances.
They explicitly use CUE4Parse Conversion's public
`TextureDecoder.UseAssetRipperTextureDecoder` path. BC4 is validated as a
single red scalar channel, BC5 against its reconstructed normal Z channel, and
BC6H against the 8-bit clamped bitmap produced by the current Skia conversion.
Generated cube, array, and volume textures are checked against their procedural
per-slice pixel pattern. The virtual-texture fixture validates parsed tile/chunk
metadata and compares its fully decoded bitmap with the same deterministic
512x512 reference. `SourceAudio` retains the inline and streaming mono PCM
references; the shared compression-matrix source is omitted because no test
reads it. Tests decode the inline, streaming, and compression-matrix PCM
SoundWaves through CUE4Parse, parse their RIFF chunks, and validate metadata and
signal characteristics without requiring byte-for-byte equality. All seven UE 5.8
`ESoundAssetCompressionType` choices remain cooked in the containers, but the
tests intentionally do not invoke external codec decoders.

## Mappings

- `CUE4ParseFixtures-Oodle.usmap` is the Oodle-compressed mapping dump.
- `CUE4ParseFixtures-Uncompressed.usmap` is the same dump without compression.

The mapping dump is treated as fixture data, not as an unquestionable oracle.
When a schema assertion fails, validate the expected test value and compare the
mapping against the native fixture declarations before investigating CUE4Parse.

The dump intentionally contains no properties flagged `CPF_EditorOnly`. These
fixtures exercise cooked runtime schemas and values; editor-only mappings and
the absence of editor-only properties are outside the test scope.

The source cooks omit editor content. Their 52 test packages were repacked
without recooking into dedicated Oodle and uncompressed minimal IoStore
containers. Compression is a packaging choice, so both modes use the exact same
cooked package bytes and schema. The mappings cover the expanded runtime schema,
including optional properties, fixed arrays, delegates, and `FInstancedStruct`.

## IoStore

`IoStore/Tagged` and `IoStore/Unversioned` each contain `Oodle` and
`Uncompressed` subdirectories. Their named minimal `.utoc/.ucas` pairs contain
the same map, expanded DataAsset, DataTables, curve assets, StringTable,
textures, static and skeletal meshes, animation assets, materials, a material
parameter collection and Level Sequence, a Blueprint generated class, an
offline font, a Geometry Collection, and audio assets. The 52 package entries
and twelve required bulk-data sidecars are exactly the files exercised by
tests; Nanite resources and virtual-texture tiles each have their own sidecar.
Every package entry in an Oodle pair must use Oodle; every entry in an
uncompressed pair must use `None`. Each serialization directory stores one
shared `global.utoc/global.ucas` pair required for script-object data, avoiding
a duplicate global payload.

The large staged runtime PAK files and native Shipping binaries are
intentionally excluded. Engine assets and shader libraries are also excluded
from these repository-hosted test containers.

## Pak

`Pak/Oodle` and `Pak/Uncompressed` contain equivalent deterministic minimal
Paks. Each has exactly four entries: a neutral-English `DefaultGame.ini`,
Engine-generated English and German LOCRES resources, and the cooked runtime
`AssetRegistry.bin`. Tests mount both variants, verify compression metadata,
parse the INI and both LOCRES files, switch `en`/`de` through CUE4Parse's
internationalization manager using the fixed `CUE4ParseFixtures.Tests` namespace
and `CityGreeting` key, and ensure the AssetRegistry lists every package kept in
the minimal IoStore containers. The focused files replace the roughly 10 MB
staged runtime Pak, which mostly contains unrelated Slate, font, ICU,
localization, and configuration data.
